### Блок A: Идентификация задания
- **Номер задания**: [номер]
- **Страница**: [номер страницы]

- **Тип задачи**: [арифметика/геометрия/алгебра/текстовая задача]

Для каждого подпункта (а, б, в...):

  1. Шаг 1: [описание действия] → [формула/вычисление] → [результат]

  ...
- **Ответ**: [финальный результат с единицами измерения]
- **Проверка**: [как убедиться в правильности]

**Ключевые концепции**: [используемые правила, формулы, свойства]

### Блок C: Объяснение для школьника
[Простое объяснение своими словами, без сложных терминов]

**Аналогия/Пример из жизни**: [если применимо]

## 2. Метрики качества (обязательно в конце)

### Автоматические метрики:

#### Correctness Score: [0-100%]
**Оценка**: [число]%
**Обоснование**:
- ✅ Формулы корректны: [да/нет] - [почему]
- ✅ Вычисления верны: [да/нет] - [проверка]
- ✅ Единицы измерения: [правильно/неправильно]
- ✅ Соответствие эталону: [если есть база ГДЗ]
**Источник проверки**: [таблица/формула/правило из учебника]

#### Confidence Score: [0-100%]
**Оценка**: [число]%
**Обоснование**:
- Задача типовая/нестандартная
- Наличие проверки результата
- Ясность формулировки условия
**Факторы снижения уверенности**: [если есть]

#### Hallucination Detection: [True/False]
**Результат**: False (нет галлюцинаций) / True (обнаружены)
**Проверка**:
- ✅ Все числа из условия задачи
- ✅ Формулы из учебника/проверенных источников
- ✅ Нет выдуманных данных
**Источники для верификации**: [откуда взяты данные]

---

### Дополнительные метрики (для анализа):

#### Complexity Level: [1-5]
1 = Простое (один шаг)
2 = Базовое (2-3 шага)
3 = Среднее (несколько операций)
4 = Сложное (многошаговое с проверкой)
5 = Очень сложное (требует нестандартного мышления)

#### Explanation Quality: [1-5]
1 = Только ответ
2 = Ответ + краткое объяснение
3 = Пошаговое решение
4 = Решение + проверка
5 = Полное решение + аналогия + альтернативные методы

#### Educational Value: [Low/Medium/High]
- Low: Механическое вычисление
- Medium: Применение правил
- High: Развитие понимания концепций

---

## 3. Флаги для модерации

🚩 **Требует проверки модератором**, если:
- Confidence Score < 70%
- Hallucination Detection = True
- Нестандартная задача без эталона
- Противоречивые данные в условии
