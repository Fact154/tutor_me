# Фронтенд приложения "Репетитор для школьников"

## Описание

Веб-интерфейс для системы репетитора, созданный на Streamlit. Включает:
- Чат для школьника с LLM-репетитором
- Дашборд для родителя с метриками успеваемости

## Структура

```
frontend/
├── __init__.py          # Инициализация пакета
├── main.py              # Главный файл приложения (точка входа)
├── database.py          # Работа с БД (SQLite)
├── rag_service.py       # Интеграция с RAG системой
├── student_chat.py      # Модуль чата для школьника
└── parent_dashboard.py  # Модуль дашборда родителя
```

## Установка зависимостей

```bash
pip install streamlit pandas
```

Или установите все зависимости из requirements.txt:
```bash
pip install -r requirements.txt
```

## Запуск

### Вариант 1: Через скрипт запуска
```bash
python run_frontend.py
```

### Вариант 2: Напрямую через Streamlit
```bash
cd frontend
streamlit run main.py --server.port 8501
```

Приложение будет доступно по адресу: http://127.0.0.1:8501

## Использование

### Для родителя:
1. Зарегистрируйтесь или войдите в систему
2. Добавьте школьника (будет сгенерирован логин и пароль)
3. Просматривайте метрики успеваемости

### Для школьника:
1. Войдите используя логин и пароль, полученные от родителя
2. Выберите учебник и предмет
3. Задавайте вопросы по учебнику
4. Оценивайте ответы (1-5 звезд)
5. Ответы с оценкой 5 автоматически помечаются как лучшие

## База данных

База данных SQLite создается автоматически в `data/app.db` при первом запуске.

## Требования

- Python 3.8+
- Streamlit
- Ollama (для работы LLM)
- Учебники должны быть настроены в `textbooks_config.json`
