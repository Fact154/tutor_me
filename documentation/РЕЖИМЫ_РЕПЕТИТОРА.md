# Режимы репетитора

Система поддерживает 3 режима работы репетитора с разным уровнем детализации ответов.

---

## 🎭 Доступные режимы

### 1. Стандартный (по умолчанию)
**Файл:** `promt/предпромт.txt`

**Особенности:**
- Сбалансированные ответы
- Пошаговое решение
- Простые объяснения
- Примеры из жизни (когда уместно)
- Советы по закреплению

**Когда использовать:**
- Обычная работа с учеником
- Решение типовых задач
- Объяснение новых тем

**Пример ответа:**
```
📌 Задание №5 (стр. 5-6)
[Полный текст задания]

✏️ Решение
а) Что нужно найти: Количество ясных дней в июле
Решение: Смотрим в таблицу, столбец "Июль" → 19
Ответ: 19 дней

💡 Объяснение
В таблице каждому месяцу соответствует число...

🎯 Совет: Внимательно читай названия столбцов
```

---

### 2. Краткий
**Файл:** `promt/предпромт_краткий.txt`

**Особенности:**
- Минимум текста
- Только вычисления и ответы
- Без длинных объяснений
- Быстрые ответы

**Когда использовать:**
- Ученик уже понимает тему
- Нужна только проверка ответа
- Быстрое решение нескольких задач
- Повторение пройденного материала

**Пример ответа:**
```
📌 Задание №5 (стр. 5-6)
[Краткий текст задания]

✏️ Решение
а) Ясные дни в июле
```
19
```
Ответ: 19 дней

💡 Кратко
Извлекали данные из таблицы и выполняли сложение.

🎯 Совет: Внимательно читай таблицу.
```

---

### 3. Подробный
**Файл:** `promt/предпромт_подробный.txt`

**Особенности:**
- Максимально детальные объяснения
- Теория перед решением
- Пошаговый разбор с комментариями
- Примеры из жизни
- Частые ошибки и как их избежать
- **Дополнительное задание для закрепления**
- Рекомендации по повторению тем

**Когда использовать:**
- Ученик изучает тему впервые
- Сложная или непонятная задача
- Нужно глубокое понимание
- Подготовка к контрольной

**Пример ответа:**
```
📌 Задание №5 (стр. 5-6)
[Полный текст]

🎓 Теория
[Объяснение, что такое таблица, как её читать]

✏️ Подробное решение
а) Что дано: Таблица с данными
   Что найти: Число ясных дней в июле
   
   План решения:
   1. Найти столбец "Июль"
   2. Прочитать значение
   
   Шаг 1: Ищем столбец "Июль" в таблице
   💭 Почему так: Таблица организована по месяцам...
   
   Ответ: 19 дней
   
   Проверка: Убедимся, что прочитали правильный столбец

💡 Подробное объяснение
[Развёрнутое объяснение логики]

Пример из жизни: [Аналогия]

Частые ошибки:
1. Перепутать столбцы
2. Забыть сложить все числа

🎯 Задание для закрепления
[Похожая задача с другими числами]

📚 Что ещё почитать
- Повтори тему: Работа с таблицами
```

## ⚙️ Как переключать режимы

### В интерфейсе (UI)
1. Запусти приложение: `python app.py`
2. Открой http://127.0.0.1:7860
3. В левой панели найди dropdown **"🎭 Режим репетитора"**
4. Выбери нужный режим
5. Задавай вопросы — ответы будут в выбранном стиле

### В конфигурации (textbooks_config.json)
```json
{
  "textbooks": [
    {
      "id": "math_5_tkacheva_part1",
      "preprompt_modes": {
        "Стандартный": "promt/предпромт.txt",
        "Краткий": "promt/предпромт_краткий.txt",
        "Подробный": "promt/предпромт_подробный.txt"
      },
      "default_mode": "Стандартный"
    }
  ]
}
```

Измени `default_mode` на нужный режим.

## 🎯 Оптимизация работы модели

### Параметры генерации (в app.py)
```python
options={
    'temperature': 0.3,      # Низкая → точность, высокая → креативность
    'top_p': 0.9,            # Ограничение вариативности
    'top_k': 40,             # Уменьшение случайности
    'repeat_penalty': 1.1    # Избегание повторений
}
```

### Рекомендуемые модели

**Для быстрой работы (< 8GB RAM):**
- `qwen2.5:3b` — хороший баланс скорости и качества
- `llama3.2:3b` — быстрая и умная

**Для качества (8-16GB RAM):**
- `qwen2.5:7b` — отличное качество
- `gemma2:9b` — очень хорошая для математики
- `mistral:7b` — классика

**Для максимального качества (16GB+ RAM):**
- `qwen2.5:14b` — топ для русского языка
- `qwen3:30b` — очень мощная (требует много памяти)
- `llama3.1:70b` — лучшая, но очень тяжёлая

### Установка модели
```bash
ollama pull qwen2.5:7b
```

## 📊 Сравнение режимов

| Параметр | Краткий | Стандартный | Подробный |
|----------|---------|-------------|-----------|
| Длина ответа | ~100-200 слов | ~300-500 слов | ~800-1500 слов |
| Теория | ❌ | Краткая | ✅ Полная |
| Примеры из жизни | ❌ | ✅ | ✅✅ |
| Частые ошибки | ❌ | ❌ | ✅ |
| Доп. задание | ❌ | ❌ | ✅ |
| Время генерации | ~5-10 сек | ~10-20 сек | ~30-60 сек |
| Подходит для | Проверка | Обучение | Глубокое изучение |

## 🔧 Создание своего режима

1. Создай файл `promt/предпромт_мой_режим.txt`
2. Напиши инструкции для LLM (смотри примеры в существующих файлах)
3. Добавь в `textbooks_config.json`:
   ```json
   "preprompt_modes": {
     "Мой режим": "promt/предпромт_мой_режим.txt"
   }
   ```
4. Перезапусти приложение

## 📝 Советы по использованию

### Для ученика начального уровня:
1. Начни с **Подробного** режима
2. Когда тема понятна → переключись на **Стандартный**
3. Для повторения используй **Краткий**

### Для подготовки к контрольной:
1. **Подробный** — разбор сложных задач
2. **Стандартный** — решение типовых задач
3. **Краткий** — быстрая проверка ответов

### Для экономии времени:
- **Краткий** для простых задач
- **Стандартный** для новых тем
- **Подробный** только для сложных моментов

## 🐛 Если что-то не работает

### Режим не переключается
1. Проверь, что файл предпромпта существует
2. Перезапусти приложение
3. Проверь консоль на ошибки

### Ответы не соответствуют режиму
1. Убедись, что выбран правильный режим в UI
2. Попробуй очистить чат и задать вопрос заново
3. Проверь параметры `temperature` в коде (должно быть 0.3 для точности)

### Модель "тупит"
1. Используй модель >= 7b параметров
2. Снизь `temperature` до 0.1-0.2
3. Добавь больше примеров в предпромпт
4. Попробуй другую модель (gemma2, llama3)
